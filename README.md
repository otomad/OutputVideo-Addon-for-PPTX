# PPTX 输出视频加载项

**一个 PowerPoint (2016+) 加载项，可帮助导出 60fps+ 的视频。**

[English](README_en-US.md) | **简体中文**

这是官方 `ActivePresentation.CreateVideo` 子程序的 GUI 版本。

由于 PowerPoint 菜单中的导出视频功能最多只能导出 30fps 的视频，但它实际上内置了相关子程序来导出更高帧率的视频。因此，我制作了一个图形界面来调用该子程序并允许配置其它相关选项。

## 如何使用

1. 下载此加载项的最新版本。
2. 打开 Microsoft PowerPoint 2016+。
3. 单击 PowerPoint 开始屏幕（又称后台视图、文件选项卡）中的“选项”。
4. 单击选项窗体左侧的“加载项”。
5. 在底部的“管理”下拉框中选择“PowerPoint 加载项”选项，然后单击“转到”按钮。
6. 单击“添加”按钮。
7. 在打开的对话框中找到你刚刚下载的加载项，然后将其打开。
8. 单击“关闭”按钮。
9. 在功能区菜单的“录制”选项卡中，你将看到一个名为“自定义导出视频”的新选项。
10. 选择视频导出路径。
11. 设置相关配置选项。
12. 单击“输出”按钮，然后只需等待 PowerPoint 导出视频即可。
